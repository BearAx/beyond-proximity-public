# Build the anonymous review PDF

OpenReview assigns the numeric paper ID. Build the upload PDF only with that
real ID:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_twinworld_review.ps1 -PaperId <assigned-number>
```

The script writes ignored `papers/twinworld/review_id.tex`, validates that the
ID is numeric, and performs the complete LaTeX/BibTeX build.
Do not substitute a made-up ID in the PDF uploaded to OpenReview.

From this directory:

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;" + $env:Path
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Or from repo root after regenerating shared five-scene figures:

```powershell
$env:PYTHONPATH = "."
python -B scripts\export_paper_figures.py --out-dir papers\twinworld\figures
python -B scripts\measure_graph_construction.py --repeats 7
python -B scripts\export_twinworld_figures.py
python -B scripts\export_twinworld_agent_figures.py
python -B scripts\check_twinworld_numbers.py
cd papers\twinworld
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Output: `main.pdf` (anonymous review build).

The ID-free entrypoint is `main_preprint.tex`; it defines preprint mode and
then inputs the same manuscript source.

Build the project page after the PDF and figures are current:

```powershell
python -B scripts\build_project_site.py
python -m http.server 4173 --directory site-dist
```

## Notes

- Template follows ECCV LNCS / `eccv.sty` review mode (line numbers, anonymous).
- `eccv.sty`, `llncs.cls`, and `splncs04.bst` match the official ECCV 2026
  author-kit repository at commit
  `da8c09c40239d5665757527e77388f4716a6564a` (verified 2026-07-14).
- `silence.sty` is a tiny local compatibility stub because the official kit does
  not vendor that CTAN dependency. The paper also compiles successfully with
  Tectonic 0.16.9.
- `main.tex` contains no fake paper ID. It reads the ignored `review_id.tex`
  generated by `scripts/build_twinworld_review.ps1`.
- An ID-free pre-submission PDF can be built with
  `scripts/build_twinworld_preprint.ps1`; it refreshes both `main_preprint.pdf`
  and `main.pdf`, but neither is the ECCV review upload until the review builder
  is run with the assigned numeric ID.
- Blue marginal line numbers are required in the initial ECCV review PDF. They
  are supplied by `[review]` and removed from the camera-ready version.
- For camera-ready, replace the review package line with `\usepackage{eccv}`
  and restore author/affiliation metadata from a private source. Do not store
  author identities in the anonymous review source.
